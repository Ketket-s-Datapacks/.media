# Ketket Datapack Media

This repository stores shared public media assets for the Ketket datapack ecosystem.

## Purpose

Use this repository for images that need stable public links, such as:

- Modrinth gallery images
- repository banners
- icons and thumbnails
- screenshots used in README files

## Structure

Each finished datapack has its own top-level folder:

- datapack-better-cauldrons
- datapack-better-hanging-signs
- datapack-mannequins
- datapack-display-cases
- datapack-easy-coords
- datapack-furnicraft
- datapack-graves
- datapack-player-shops
- datapack-quick-shulker-boxes
- datapack-silk-fortune-switch
- datapack-stackraft
- datapack-totem-refill

Each datapack folder contains:

- screenshots/
- banners/
- icons/
- thumbnails/

You can upload images into these folders and use the GitHub raw links wherever public image hosting is needed.
